# Housing Permitting & Prices – Empirical Research Project

This repository contains my UC Davis ECN 140 empirical project analyzing how housing permitting activity affects U.S. residential housing prices (2021-2022).

## Abstract
Using county-level data, I tested how income, permitting relative to housing stock, population growth, and geography (urban/rural, coastal) influence home values. Results show that:
- Higher local incomes and coastal/urban location correlate with higher prices.
- More permitting relative to stock is associated with moderated increases in home values.
- Findings highlight the dual role of demand fundamentals and supply elasticity in shaping affordability.

## Data
- HUD Building Permits Survey (permits)
- US Census (housing stock)
- SAIPE (median income)  
- Bureau of Economic Analysis Estimates (growth)  
- USDA RUCC codes (urban/rural dummy)  
- NOAA Coastal Counties list  
- Zillow Home Value Index (dependent variable)
